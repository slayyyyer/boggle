How Boggle Lab works

The rules

Find words of three or more letters by moving between adjacent tiles — horizontally, vertically or diagonally. A tile can be used once per word. Qu is printed on one tile, counts as two letters, and scores by its letter count. Each distinct word counts once.

The guarantee

For the shipped word list, the solver builds a trie and walks every simple path from every starting tile. It returns every word with a legal path, one path for each word, and the number of distinct paths. The maximum score is the sum of those distinct words. It is exact for that board and that dictionary — not a sample, and not a claim about every English dictionary.

The dictionary

ENABLE1, 3–16 letters, minus a short blocked-terms list. ENABLE1 is released into the public domain by its authors. The shipped file has 170,318 words and its source checksum is pinned in the repository. Words containing Q not followed by U are in the list but can never be formed: the only Q tile is Qu.

The CPU

The CPU knows the full solved list, so strength is a parameter rather than a performance. Each attempt costs time and succeeds with a probability that falls with word length. With 30 seconds left and a lead, it only attempts words it is likely to find, and may idle. When behind with 45 seconds left, it accepts risky long words because only a swing can win. It never sees your words — only the score gap.

The board lab

The sample and hill climb are measured in this browser against the full dictionary. A hill-climb result is labelled “best found” because a local search cannot prove a board is optimal.

Keyboard and limits

Type in the word box and press Enter. Escape clears. Every tile is a button, so Tab and Enter/Space also work; arrow keys are not required. The timer pauses while the tab is hidden. Only the 4×4 board ships; the solver and generator take a side parameter, but a 5×5 dice set and layout are not included.
